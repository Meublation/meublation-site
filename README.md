# Site Meublation

Code du site de l'association Meublation, publié avec GitHub Pages.

- **Pour modifier le site ou passer la main** : lire [GUIDE.md](GUIDE.md).
- **Attention** : ce dépôt est public. Ne jamais y mettre de mot de passe, de clé ou d'information privée.

| Élément | Rôle |
|---|---|
| `index.html`, `store.html`, `sell.html`, `buy.html`, `about.html` | Les cinq pages du site |
| `css/style.css` | Styles communs |
| `assets/` | Images, logo, bannière |
| `GUIDE.md` | Guide de passation |
| `.nojekyll` | Dit à GitHub de publier les fichiers tels quels |
